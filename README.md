# Moon Mind's Eye

Photograph the low "huge" moon the way your brain sees it.

- Single static page: `index.html` (no build step)
- Hosted on Render as a static site (publish directory: `.`)
- Uses the phone's GPS and compass when opened from its own web address in Safari
- Moon images are our own: generated by `tools/make_moon.py` (albedo + normal maps), lit in the browser to tonight's real phase and tilt
- AI sky detection: SegFormer-B0 fine-tuned on ADE20K (`Xenova/segformer-b0-finetuned-ade-512-512`), run in the browser with Transformers.js (loaded from jsDelivr / Hugging Face on first use, then cached). NVIDIA's SegFormer license is for non-commercial use; swap the model before selling the app.
